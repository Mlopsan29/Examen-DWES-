 Vamos a diseñar un juego para adivinar imágenes mostrando solo alguna parte de ellas. Dividir una
imagen en un mosaico de 3x3, y mostrar una cuadrícula en la página principal con todos los cuadrados
del mosaico dados la vuelta. Debajo de la cuadrícula habrá una caja de texto para que el usuario intente
adivinar el nombre de lo que aparece en la imagen, junto a un botón comprobar.
Cada vez que el usuario pulse en un cuadrado de la cuadrícula se mostrará el contenido solo de esa
cuadrícula durante 2 segundos y posteriormente se volverá a ocultar.

Cuando el usuario escriba algo y pulse el botón comprobar ocurrirá lo siguiente:

-Si ha acertado se mostrará la imagen completa y un mensaje de felicitación por acertar.
-Si no ha acertado se mostrará un mensaje indicando que ha fallado y un botón de volver para seguir
intentándolo. 



================================================================================
EXPLICACIÓN TÉCNICA - EJERCICIO: JUEGO ADIVINAR IMAGEN (MOSAICO 3x3)
================================================================================

1. ARQUITECTURA CLIENTE: MOSAICO E INTERACCIÓN (index.html + CSS + JS)
--------------------------------------------------------------------------------
- Cuadrícula 3x3 con CSS Grid:
  * El contenedor '.tablero' usa:
      display: grid;
      grid-template-columns: repeat(3, 100px);
      grid-template-rows: repeat(3, 100px);
    Esto genera automáticamente una cuadrícula rígida de 9 celdas idénticas
    de 100x100 píxeles.

- Técnica de fondo único (CSS Sprites / background-position):
  * En lugar de recortar la imagen en 9 archivos distintos, se carga la imagen
    completa de 300x300 px como fondo en cada celda (background-size: 300px 300px).
  * Mediante clases de posición (.pos-0 a .pos-8), se desplaza la coordenada
    de visualización con 'background-position' en saltos de -100px (ejes X e Y),
    mostrando únicamente el fragmento correspondiente en cada casilla.

- Mecánica de ocultación y temporizador en JavaScript (DOM):
  * Estado tapado: La clase CSS '.tapada' aplica un color sólido azul oscuro
    y anula la imagen de fondo, simulando que la pieza está "dada la vuelta".
  * Evento 'onclick': Al pulsar sobre un cuadrado se ejecuta 'destapar(this)'.
  * Revelado temporal: 
      elemento.classList.remove('tapada'); // Destapa la casilla
  * Temporizador nativo:
      setTimeout(function() {
          elemento.classList.add('tapada');
      }, 2000);
    La función nativa setTimeout() programa la ejecución del callback a los 
    2000 milisegundos (2 segundos), volviendo a colocar la clase '.tapada'.


2. VALIDACIÓN Y LÓGICA EN EL SERVIDOR (comprobar.php)
--------------------------------------------------------------------------------
- Recepción de datos vía POST:
  * El formulario envía el valor del input hacia 'comprobar.php' mediante el 
    método POST para procesarlo en el lado del servidor.

- Sanitización y comparación de cadenas (Strings):
  * isset($_POST['respuesta']): Comprueba la existencia del parámetro antes
    de procesar para evitar avisos 'Undefined array key'.
  * trim(): Elimina posibles espacios en blanco involuntarios al inicio y 
    al final introducidos por el usuario.
  * strtolower(): Convierte tanto la cadena del usuario como la palabra 
    secreta a minúsculas. Así la comparación no es sensible a mayúsculas/minúsculas 
    (Case-insensitive: valida igual "Perro", "PERRO" o "perro").

- Seguridad en la salida (XSS):
  * htmlspecialchars(): Se aplica al imprimir el intento del usuario en el 
    HTML para neutralizar caracteres especiales (<, >, &, ") y prevenir 
    inyecciones de código malicioso (Cross-Site Scripting).

- Renderizado condicional (Control de flujo):
  * Se utiliza una estructura alternativa limpia en PHP:
      if ($acierto): ... else: ... endif;
  * Si acierta: Muestra mensaje de felicitación, la etiqueta <img> con la foto 
    completa y el enlace para reiniciar.
  * Si falla: Muestra mensaje de error con el texto introducido y un botón 
    para regresar al formulario sin perder el contexto.
